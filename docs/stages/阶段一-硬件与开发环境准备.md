## 📋 操作步骤

### 1.1 获取开发板（INF-01）
- 紫光同创提供 **200 套盘古50 和盘古676 开发板借用**名额。
- **立刻**联系竞赛官方或小眼睛科技客服（微信/电话：**17665247134**）申请**免费借用**。
- ✅ 目标：省下购买费用。**这一步不要拖，板卡到位时间直接决定整个项目起点。**

### 1.2 安装 PDS 开发工具（INF-02）
1. 从**紫光同创官网**下载 Pango Design Suite (PDS)。
2. 优先选择与**开发板资料配套的版本**。
3. 安装路径**不要含中文或空格**，建议默认路径如 `C:\pango\PDS_2022.1`。
4. **安装前关闭杀毒软件和防火墙**。

### 1.3 安装 USB-JTAG 驱动（INF-03）
1. 驱动通常在安装目录下，如 `C:\Pango\PDS_2021\drivers\pgc_jtag_driver.exe`。
2. 设备管理器出现**黄色感叹号**时，**手动指定该路径**更新驱动。
3. 验证：下载器可被 PDS 识别。

### 1.4 安装 RISC-V 工具链（INF-04）
- 下载并安装 **SiFive Freedom Studio** 或同类 RISC-V 开发工具。
- 用途：软核程序开发与调试（阶段三会用到）。

### 1.5 建立工程骨架（INF-05，建议）
```
ziguang/
├── rtl/        # Verilog 源码
├── sim/        # 仿真 testbench
├── constr/     # 时序约束 .fdc
├── sw/         # RISC-V 软核 C 程序
├── ip/         # PDS IP 核
├── doc/        # 文档
└── README.md
```
`git init` 并完成首次提交。

## 📋 操作步骤

### 6.1 时序约束与收敛（SYS-01 / SYS-02 / SYS-03）
- **早期约束介入**：在设计初期就创建**完整的时序约束**，包括**所有时钟、I/O 延时和例外路径**。
  （阶段四起就应持续维护，本阶段是**收口**。）
- 对 **PLL 输出的衍生时钟**、**高速收发器恢复时钟**正确定义**生成时钟关系**。
- 对**跨时钟域的异步 FIFO** 设置 `set_clock_groups` 或 `set_false_path`。
- 🎯 确保在 **720P/30fps 或 1080P/30fps** 下**时序无违例**。

### 6.2 鲁棒性测试（SYS-04 / SYS-05 / SYS-06）
用**官方现场数据集**（十字路口、变道、红绿灯）和自找的**夜间、逆光、多车牌**视频测试系统，记录：

| 功耗数据 | 静态 / 动态 | ______ |

### 6.3 提交材料准备（DOC-01 / DOC-02 / DOC-03）
- **技术文档**：完整系统架构、模块划分、**接口时序**、技术亮点、量化数据。
- **3 分钟演示视频**：包含**夜间/白天多车牌识别效果**、**软硬协同讲解**。
- **工程源码**：整理规范，附 **README 说明编译和运行流程**。

> ⏰ **建议 W13 就并行启动材料准备**，不要等联调完全结束 —— W13–W16 挤了 7 个 P0。

### 6.4 答辩 PPT 制作（DOC-04）
按逻辑线组织：

```
行业痛点 → 整体方案 → 技术亮点 → 性能数据 → 应用价值 → 总结展望
```

## ⚠️ 避坑
- 时序约束**后期才补** → 大量违例 + 返工成本极高。
- PLL 衍生时钟 / 收发器恢复时钟未定义 → 时序分析结果**失真**（看似收敛，实则不收敛）。
- 跨时钟域异步 FIFO 未约束 → **亚稳态**，表现为偶发错误，极难复现。
- 材料压到最后一周写 → 文档质量差、演示翻车。

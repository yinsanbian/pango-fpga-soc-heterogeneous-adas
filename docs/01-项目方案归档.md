# 01 · 项目方案归档（原始版 · 六阶段完整实施方案）

> 本文件为项目方案的**全文归档**，保留原始阶段划分、操作步骤与避坑提示，供追溯与对照。

**项目代号**：夜瞳多目
**定位**：夜间多车牌识别 —— 纯硬件流水线 + RISC-V 软核协同
**总周期**：16 周

## 📦 阶段一：硬件与开发环境准备（第 1 周）

### 1.1 获取开发板
紫光同创提供 **200 套盘古50 和盘古676 开发板借用**名额，建议立刻联系竞赛官方或小眼睛科技客服
（微信/电话：**17665247134**）申请**免费借用**，省下购买费用。

### 1.2 安装 PDS 开发工具
- 从**紫光同创官网**下载 Pango Design Suite (PDS)，优先选择与开发板资料**配套的版本**。
- 安装路径**不要含中文或空格**，建议用默认路径如 `C:\pango\PDS_2022.1`。
- 安装前**关闭杀毒软件和防火墙**，否则 JTAG 驱动可能被误删。

### 1.3 安装 USB-JTAG 驱动
驱动文件通常在安装目录下，如 `C:\Pango\PDS_2021\drivers\pgc_jtag_driver.exe`。
设备管理器出现**黄色感叹号**时，手动指定该路径更新驱动。

### 1.4 安装 RISC-V 工具链
下载并安装 **SiFive Freedom Studio** 或同类 RISC-V 开发工具，用于软核程序开发与调试。

## 🔌 阶段二：打通基础数据通路（第 2–3 周）

### 2.1 跑通第一个工程：LED 闪烁
在 PDS 中新建工程，选择器件 **PGL50H-6IFBG484**，编写 LED 闪烁 Verilog 代码并烧录，
验证**工具链和下载器**正常工作。

### 2.2 跑通 HDMI 环通示例
开发板配套例程中通常有 **HDMI 环通示例**，直接跑通它，验证 HDMI **输入/输出硬件通路**正常。

### 2.3 跑通 DDR3 读写测试
DDR3 带宽是图像缓存的关键。核心板搭载 **2 颗 512MB DDR3，32 位总线，理论峰值带宽 25.6 Gbps**。
跑通官方 DDR3 读写例程，实测连续读写带宽应能**稳定在 20 Gbps 以上**。

### 2.4 搭建 摄像头采集 → DDR3 缓存 → HDMI 显示 全链路
- 使用 **OV5640 摄像头**，参考官方 **OV5640 双目摄像头实验例程**。
- 实现 **乒乓操作**（两个 DDR3 帧缓存交替读写），避免画面撕裂。
- **目标**：摄像头画面实时显示在 HDMI 显示器上。

> ⚠️ **避坑提示**：DVP 接口的**像素有效信号必须结合 HREF 和 PCLK 生成**，
> 直接使用 PCLK 采样会导致**边界像素错位**。

---

## 🧠 阶段三：SoPC 框架搭建与 RISC-V 软核集成（第 4–5 周）

### 3.1 配置 RISC-V 软核
紫光同创官方提供 **RISC-V 软核 IP**，在 PDS 中将其例化到顶层，分配**指令/数据存储器地址空间**。

### 3.2 搭建 AXI 总线互联
- 在 FPGA 逻辑中搭建 **AXI4-Lite** 或 **AHB/APB** 总线互联，让 RISC-V 软核能与图像处理模块通信。
- 软核负责配置图像处理参数（如**对比度阈值**）和控制 **HDMI 字幕叠加**。

### 3.3 编写软核程序
在 Freedom Studio 中编写 C 程序，通过总线读写寄存器来控制外设。
**软核不参与任何 AI 推理，只做系统调度。**

> ⚠️ **避坑提示**：自定义外设模块需要**编写总线接口**，并在软核地址空间中**分配寄存器地址**才能访问。

## 🖼️ 阶段四：图像预处理流水线实现（第 6–8 周）

### 4.1 实现行缓存（Line Buffer）
- 使用**双口 RAM** 实现行缓存，存储两行图像数据。
- 对于 1080P 图像，行缓存深度为 **1920**，宽度 **8 位（灰度）**。
- 设计 **3×3 窗口生成逻辑**，从当前行和前两个缓存行中并行取出 9 个像素。

### 4.2 实现灰度化与高斯滤波
- **灰度化**：`Y = 0.299R + 0.587G + 0.114B`，用 **DSP 切片**实现乘法运算。
- **高斯滤波**：用 **3×3 卷积核**实现，行缓存输出的 9 个像素与卷积核权重相乘后累加。

### 4.3 实现夜间增强模块（核心创新点）
- 先实现 **全局直方图均衡化** 作为**保底方案**。
- 进阶实现 **CLAHE**（限制对比度自适应直方图均衡化）：将图像分块后分别做直方图均衡，
  再**双线性插值**消除块效应。
- 用 **Python/Matlab 先验证算法效果**，再移植到 Verilog。

### 4.4 实现 Sobel 边缘检测
用行缓存输出的 **3×3 窗口**计算水平和垂直梯度，求出**梯度幅值**。

> ⚠️ **避坑提示**：行缓存的读写指针时序必须与 **pixel_valid** 信号严格对齐，否则窗口像素会错位。
> 推荐用**流水线寄存器在每级之间打拍**，确保数据同步。

## 🤖 阶段五：AI 识别与注意力机制加速（第 9–12 周）

### 5.1 训练轻量化 LPRNet 模型
- 在 PC 端用 **PyTorch** 训练一个修改版的 **LPRNet**，加入 **CBAM 注意力机制**
  （通道注意力 + 空间注意力）。
- 使用 **CTC 损失函数**处理不定长车牌字符序列，推理时用**贪心解码**去除重复字符和空白符。
- 数据集建议使用 **TLPD（台湾车牌数据集）** 或自建数据集，**包含白天和夜间场景**。

### 5.2 模型量化与权重导出
- 将训练好的模型进行 **INT8 量化**，减少计算量和存储需求。
- 导出量化后的权重和偏置为**十六进制文件（.mem 或 .coe）**，供 Verilog 模块通过 `$readmemh` 加载。

### 5.3 实现 CBAM 注意力模块硬件加速器
- **通道注意力**：对特征图做全局平均池化，通过两层全连接学习各通道权重，再逐通道相乘。
- **空间注意力**：对特征图做最大/平均池化，拼接后经 **7×7 卷积**生成空间权重图。
- 参考开源实现：GitHub 上 **NeuroMove/fpga/rtl** 项目中有完整的 CBAM RTL 实现，
  包含 `cbam_channel_attn` 和 `cbam_spatial_attn` 模块。

### 5.4 实现 CNN 推理加速器
- 将 LPRNet 的卷积层展开为**流水线结构**，用 **DSP 切片**做乘累加运算。
- 用 **AXI4-Stream 接口**串联各层，特征图以**流式方式**在模块间流转。

### 5.5 NMS 硬件加速（多车牌场景）
- 设计 **K 路并行**的非极大值抑制电路，候选框的**重叠面积计算和得分排序并行执行**。
- 按 **30fps、每帧 4–6 个车牌**计算，NMS 模块需支持约 **180 个候选框/秒**的吞吐量。

> ⚠️ **避坑提示**：如果第 12 周时纯硬件 AI 加速仍无法收敛，**果断降级为「纯硬件预处理 + 软核跑 AI」架构**。
> **系统闭环稳定比加速比更重要。**

## 🔧 阶段六：系统联调、时序收敛与材料准备（第 13–16 周）

### 6.1 时序约束与收敛
- **早期约束介入**：在设计初期就创建完整的时序约束，包括**所有时钟、I/O 延时和例外路径**。
- 对 **PLL 输出的衍生时钟**、**高速收发器恢复时钟**正确定义**生成时钟关系**。
- 对跨时钟域的**异步 FIFO** 设置 `set_clock_groups` 或 `set_false_path`。
- 确保在 **720P/30fps 或 1080P/30fps** 下时序**无违例**。

### 6.2 鲁棒性测试
用**官方现场数据集**（十字路口、变道、红绿灯）和自找的**夜间、逆光、多车牌**视频测试系统，记录：
- 识别准确率
- 端到端延迟（**目标 < 10ms**）
- 资源占用（LUT / DSP / BRAM）
- 功耗数据

### 6.3 提交材料准备
- **技术文档**：完整系统架构、模块划分、接口时序、技术亮点、量化数据。
- **3 分钟演示视频**：包含夜间/白天多车牌识别效果、软硬协同讲解。
- **工程源码**：整理规范，附 README 说明编译和运行流程。

### 6.4 答辩 PPT 制作
按「**行业痛点 → 整体方案 → 技术亮点 → 性能数据 → 应用价值 → 总结展望**」的逻辑线组织，重点突出：
- **纯硬件流水线的加速比**（比 ARM 软核快 XX 倍）
- **CBAM 注意力机制对识别准确率的提升**（参考已有研究从 **88.33% 提升至 95.00%**）
- **夜间增强前后的 PSNR/SSIM 对比**

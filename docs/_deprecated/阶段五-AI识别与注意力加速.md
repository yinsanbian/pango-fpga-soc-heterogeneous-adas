## 📋 操作步骤

### 5.1 训练轻量化 LPRNet 模型（AI-01 / AI-02）
- 在 PC 端用 **PyTorch** 训练一个**修改版的 LPRNet**，加入 **CBAM 注意力机制**
  （通道注意力 + 空间注意力）。
- 使用 **CTC 损失函数**处理**不定长车牌字符序列**。
- 推理时用**贪心解码**：**去除重复字符和空白符**。
- 数据集：**TLPD（台湾车牌数据集）** 或自建，**必须包含白天和夜间场景**。

### 5.2 模型量化与权重导出（AI-03）
- 将训练好的模型进行 **INT8 量化**，减少计算量和存储需求。
- 导出量化后的**权重和偏置**为**十六进制文件（.mem 或 .coe）**。
- 供 Verilog 模块通过 **`$readmemh`** 加载。

### 5.3 实现 CBAM 注意力模块硬件加速器（AI-04 / AI-05）
- **通道注意力**：对特征图做**全局平均池化** → 通过**两层全连接**学习各通道权重 → **逐通道相乘**。
- **空间注意力**：对特征图做**最大/平均池化** → **拼接** → 经 **7×7 卷积**生成**空间权重图**。
- 📚 参考开源实现：GitHub 上 **NeuroMove/fpga/rtl** 项目中有完整的 CBAM RTL 实现，
  包含 `cbam_channel_attn` 和 `cbam_spatial_attn` 模块。

### 5.4 实现 CNN 推理加速器（AI-06）
- 将 LPRNet 的**卷积层展开为流水线结构**，用 **DSP 切片**做**乘累加**运算。
- 用 **AXI4-Stream 接口串联各层**，特征图以**流式方式**在模块间流转。

### 5.5 NMS 硬件加速（AI-07，多车牌场景）
- 设计 **K 路并行**的非极大值抑制电路。
- 候选框的**重叠面积计算**和**得分排序并行执行**。
- 吞吐指标：按 **30fps、每帧 4–6 个车牌**计算，需支持约 **180 个候选框/秒**。

### 5.6 🚨 W12 Go/No-Go 决策点（AI-08）
> **如果第 12 周时纯硬件 AI 加速仍无法收敛，果断降级为「纯硬件预处理 + 软核跑 AI」架构。**
> **系统闭环稳定比加速比更重要。**

决策表：

| 判据 | 走方案 A（纯硬件 AI） | 走方案 B（降级） |
|---|---|---|
| CNN 加速器仿真通过 | ✅ | ❌ |
| 综合后时序可收敛 | ✅ | ❌ |
| 资源占用 < 80% | ✅ | ❌ |
| 距离 W16 剩余时间 | 充裕 | 紧张 |

**无论走哪条路，都必须留下书面决策记录。**

## ⚠️ 避坑
- 浮点权重直接进 FPGA → 资源爆炸，必须 **INT8 量化**。
- CTC 解码忘了去重/去空白 → 输出像 `京A京A123`。
- **死磕纯硬件 AI 到超期 = 全盘皆输**，W12 是硬门限。

## 附：由 `--dup` 静态检查发现的"同脚多用途"（需设计时确认）

| 引脚 | 被谁共用 | 判定 |
|---|---|---|
| `R17` | `HD_RX_RSTN`（MS7200）与 `HD_TX_RSTN`（MS7210） | **硬件共用一根复位网络**，收发不能独立复位——软件初始化序列必须同时迁就两颗芯片 |
| `W22` | `HD_RX_MU_MC`（MS7200 Mute/主时钟）与 `HD_TX_SC_MC`（MS7210 I2S 时钟） | 同一引脚两义，**收发音频不能同时用**；本工程只用视频，无影响 |
| `B2/B3/A2/A3/C5` | 用户 LED × 官方例程状态指示 | 软复用，见上表 #15 |
| 28 个 `EX_IO_*` | 40pin 扩展口 与 OV5640 摄像头 | 同一个座，不是冲突（见表 #14） |

> 复现命令：`python scripts/pinmap_query.py --dup`

## 使用纪律

1. 任何引脚写进 `.pcf`/`.fdc` 前，先在本台账与 `pinmap.md` 各查一次；两者都没有 → 用 PDS 器件视图复核，**不要猜**。
2. 手册的"原理图"章节只有**连接示意框图与关键网络**，没有完整网表。真要逐网络追线，需向厂商索取完整原理图 PDF。
   （桌面的两个 `.dxf` 是 **PADS 导出的 PCB 版图**，同样**不含网表** —— 详见 `manual-1v1-delta.md` §7。）
3. 上表中标注"不冲突/属笔误"的条目，仍建议在周会同步一次，避免不同人按不同理解改约束。
4. **版本优先**：1V1(38页) 为现行版本；两版**引脚零差异**，故 V1.0 的引脚数据仍可用，
   但**器件型号与表述以 1V1 为准**（见 `manual-1v1-delta.md`）。
5. 本技能 `schematics/` 的图**逐图取两版更清晰者**，文件名里的图号以 1V1 的图号体系为准（与 V1.0 同号）。

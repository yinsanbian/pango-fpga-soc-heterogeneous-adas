# Verilog 提交前自检门禁

服务于 `docs/04-工作流程.md` §3.1 第⑤步前置 与 §3.3 流水线纪律（目标 ID：**ALG-07, SYS-01**）。

## ⚠️ 环境前提（重要）

**本机没有安装 `iverilog` / `verilator` / `yosys`**，git CLI 也不可用。
因此本 skill 定位是 **"提交前自检"**，不是替代仿真：

| 能力 | 现状 |
|---|---|
| 静态检查（本 skill） | ✅ 本机可做 |
| 功能仿真 | ❌ 需先装 iverilog（**W2 前建议装上**） |
| 综合/时序 | ❌ 需 PDS |

> **建议**：W2 前装好 iverilog（`scoop install iverilog` 或官网安装包），否则阶段四的所有模块都只能"盲写"，风险极高。

## 检查项清单

拿到 `rtl/` 下待提交的 `.v`，逐条核对并在 `reports/lint_<模块>.md` 打勾：

### 1. 结构类
- [ ] 每个 `always` 块只有一个时钟沿（`posedge clk`），无混合沿
- [ ] `always @(*)` 中**所有**分支都给同一变量赋值（否则推断 **latch**）
- [ ] `case` 有 `default`；`if` 链完整
- [ ] 无组合逻辑环路（A 依赖 B、B 依赖 A）
- [ ] 复位为**异步低有效** `rst_n`，且复位值确定

### 2. 位宽类（最易出错）
- [ ] **赋值两侧位宽一致**，或显式截断/扩展
- [ ] 乘法结果位宽足够：`8bit × 8bit → 至少 16bit`；**累加器再加 `log2(N)` 位**
- [ ] `>>` 移位后位宽变化已考虑（定点 Q 格式对齐）
- [ ] 有符号运算用 `$signed`，**int8 权重做乘加时必须显式处理符号** ★易错

### 3. 流水线与 valid 对齐（本项目纪律核心）
- [ ] **文件头有 `// LATENCY: <N> cycles` 登记**
- [ ] 每个功能级之间**有寄存器**，无长组合路径
- [ ] `*`_tvalid / tuser(SOF) / tlast(EOL) **与数据同一级打拍**，未错位
- [ ] **行缓存读地址推进与 `pixel_valid` 同源**（禁独立计数器）—— 避坑 #9
- [ ] 3×3 窗口移位使能 = `pixel_valid`

### 4. 跨时钟域（CDC）
- [ ] 所有跨域信号经**两级同步器**或**异步 FIFO**
- [ ] 多 bit 总线跨域**没有**直接用打两拍（必须用 FIFO 或格雷码）
- [ ] 每个 CDC 点已登记到 `constr/` 约束清单

### 5. 可综合性
- [ ] 无 `initial` 赋初值（除 testbench）
- [ ] 无 `#delay`、无 `$display`（除仿真专用 `ifdef`）
- [ ] 无对同一变量多驱动
- [ ] 无实数/浮点运算

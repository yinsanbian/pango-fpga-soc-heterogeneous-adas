# KPI 数据看板维护

服务于 `docs/04-工作流程.md` §七（目标 ID：**SYS-04, SYS-05, DOC-01, DOC-04**）。

## 何时用

- 每周五更新（见 §五 周节奏）
- 每个阶段门禁 M1–M6 评审前必须刷新
- 答辩 PPT 出数据前**必须**跑一次

## 原则

> 02 文档原文：**"这些数字直接进 PPT，必须实测，不许估算。"**
> 本 skill 的作用是**保证每个数字都有可追溯的测量方法、原始记录和测量环境说明**。

## 每个数字必须附带的元信息

缺以下任一项，该数字**不得进 PPT**：

1. **测量方法**（怎么测的）
2. **测量环境**（比特流版本 / 时钟频率 / 分辨率 / 数据集）
3. **原始证据文件**（`reports/` 下的记录或截图）
4. **样本量与统计**（延迟类必须给 均值 + P99 + 最大，不能只报均值）

## 三个高危 KPI 的专门口径

| KPI | 高危点 | 必须这样做 |
|---|---|---|
| **8 夜间增强 PSNR/SSIM** | "增强后 vs 增强前"互比**是错的** | 按 §7.3 三选一并写明：①白天参考 ②长曝光参考 ③无参考指标（对比度/熵/梯度） |
| **7 加速比** | 变量不受控则数字无效 | 同层、同频、同输入、同定点精度；**软核只跑单层**，不跑整网（见 §7.2） |
| **2 端到端延迟** | 只报均值 | 报 均值 / P99 / 最大；并写明测量点（DVP 首像素 → OSD 输出） |

## 答辩 PPT 数据页（直接引用）

按 03 文档 §四「PPT 数据预留位」填充，**答不上来源的数字一律删除**：

- 纯硬件流水线加速比：比 ARM 软核快 `__` 倍
- CBAM 准确率：`__%` → `__%`
- 夜间增强 PSNR：`__` dB → `__` dB ｜ SSIM：`__` → `__`
- 端到端延迟：`__` ms ｜ DDR3 实测带宽：`__` Gbps
- 资源：LUT `__` / DSP `__` / BRAM `__` ｜ 功耗：静 `__` W / 动 `__` W

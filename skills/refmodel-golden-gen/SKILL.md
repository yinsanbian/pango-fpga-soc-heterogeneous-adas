# 参考模型与金标准激励生成

服务于 `docs/04-工作流程.md` §3.1 第①④步（目标 ID：**ALG-01 ~ ALG-06**）。

## 何时用

- 写任何图像预处理模块前（**避坑 #11：先 Python 验证再写 Verilog**）
- 需要为 testbench 生成输入激励与期望输出
- 需要产出 PPT 用的增强前后对比数据

## 环境

本机已装：`numpy` / `scipy` / `scikit-image` / `Pillow`。**未装 cv2、matplotlib、torch** —— 用 `skimage` 与 `PIL` 替代，出图用 PIL，避免引入新依赖。

## 统一工作流

```
model/ref_<算法>.py
   ├─ ① 浮点参考实现（可读性优先）
   ├─ ② 定点仿真实现（Q8/Q10，与 RTL 位宽一致）
   ├─ ③ 误差比对：max|定点-浮点| ≤ 1 LSB
   └─ ④ 导出 sim/vectors/*.mem 与 sim/golden/*.mem（%02x 每行一像素）
```

## 关键约定

- **`.mem` 格式**：每行一个十六进制字节，`%` 用 `f"{v:02x}\n"`；**行序 = 光栅扫描序**。
- **定点参数集中定义在一个 `Q` 字典**，②④ 共用，**禁止两处各写一份**（否则"仿真对、上板错"）。
  ```python
  Q = {"gray": (8, 8), "gauss": (10, 6), "clahe_gain": (8, 4)}
  ```
- 输入图统一转为 8bit 灰度，尺寸取 **1920×1080 或小尺寸切片（如 64×64）**；做逐拍比对用小尺寸，做效果对比用全尺寸。

## 各算法实现要点

| 算法 | 目标 ID | 要点 |
|---|---|---|
| 灰度化 | ALG-02 | `Y=0.299R+0.587G+0.114B` → 定点建议 `(77R+150G+29B)>>8`，误差 ≤1 LSB |
| 高斯 3×3 | ALG-03 | 核 `[1 2 1;2 4 2;1 2 1]/16`，**边界处理方式必须与 RTL 一致**（建议复制边缘） |
| 全局 HE | ALG-04 | 先全帧统计直方图 → 累计 → 映射表 LUT。**保底方案** |
| **CLAHE** | ALG-05 | 分块（建议 8×8 块）+ 对比度限幅（clip limit）+ **双线性插值**消除块效应（避坑 #12） |
| Sobel | ALG-06 | 幅值用 `|Gx|+|Gy|` 避免开方（省资源），**RTL 需同式** |

> ⚠️ **CLAHE 是模块四的核心创新点**，但资源风险高（R3）。**先跑通全局 HE（ALG-04）保交付，再上 CLAHE。**

## PSNR/SSIM 口径（重要）

**不要用"增强后 vs 增强前"算 PSNR/SSIM** —— 那是无意义指标。
按 `docs/04-工作流程.md` §7.3 三选一，**并在报告里写明选了哪种**：

- ① 与同场景白天参考图比
- ② 与多帧长曝光平均比
- ③ **无参考指标兜底**：对比度增益 / 信息熵 / 平均梯度

## 产出

- `model/ref_<算法>.py`
- `sim/vectors/<模块>_in.mem`、`sim/golden/<模块>_out.mem`
- `reports/metrics_<算法>.md`：误差表 + 效果指标 + 对比图（存 `reports/img/`）
